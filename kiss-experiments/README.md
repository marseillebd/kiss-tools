This directory contains a bunch of experiments that help me probe
  what the kiss tools actually needs to contain and how I should go about doing it.
It is a Haskell project because Haskell is so fluid.
There are both library and executable components.

Do not be afraid to create new executables to try stuff out.
Library components are just so several executables could use them.
If part of the library gets good enough, I'll split it out into a proper package.
